# Story: Group Standings From Predictions

## User Story

As a participant, I want to see the group classification generated by my predicted match scores so that I can understand how my predictions affect the group table and compare it with the real final order when the admin reveals results.

## Acceptance Criteria

1. Given a participant is filling group-stage predictions, when a group tab is visible, then the page shows the simulated group table using the participant's scores.
2. Given another participant's predictions are revealed, when viewing a group in "Todos os Palpites", then the page shows the simulated group table for the selected participant.
3. Given all real results for a group are available, when the table is shown, then the page also shows the real group order and group classification points.
4. Given an admin creates a knockout match, when selecting Seleção 1 and Seleção 2, then those fields use country comboboxes and submit valid team names/codes.

## Implementation Notes

- Reused the previous bolão ordering rules: total points, goal difference, goals for, then team name.
- Group classification points are displayed as 5 points for exact full group order and 0 otherwise when the real group table is complete.
- This story adds the visualization first; deeper persistence of group classification points into ranking can be evolved if the final rule needs partial scoring.
